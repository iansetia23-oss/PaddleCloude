Cara pasang di GitHub Pages

  1. Buat repository baru di GitHub, lalu unggah file ini dengan nama persis index.html di root repo (atau di folder /docs).
  2. Buka Settings → Pages, pilih branch (mis. main) dan folder (/root atau /docs), lalu simpan.
  3. Tunggu sebentar, halaman akan aktif di https://namauser.github.io/nama-repo/.
Catatan: model OCR (beberapa MB) diunduh dari CDN publik Paddle.js saat halaman pertama dibuka — perlu koneksi internet sekali di awal, setelahnya browser menyimpannya di cache. Semua pemrosesan foto tetap berjalan lokal di perangkat pengguna, foto tidak pernah diunggah ke server.
